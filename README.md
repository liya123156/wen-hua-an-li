# 文化案例工作台

丽兹行上海文化案例征集。主导航仅三个目录：粘贴案例、案例库、案例评选。

## 使用

- 粘贴现有模板，识别字段后确认并提交。正文至少300字。
- 21家门店共享案例数据；按月份、价值观、门店及关键词查看。
- 每个主题最多推荐3篇达到文本初筛条件的候选，不足时显示缺口与完善建议。
- 自动初筛采用明确的文本规则与原文证据，属于辅助判断，不是大模型语义评审或事实核实。最终获奖由负责人确认。
- 提交成功后保存修改链接。修改密钥位于URL片段中，只有持有该链接的人可修改对应记录；通用分享链接不携带修改密钥。

## 数据

复用已有 Supabase 项目，独立表 `culture_cases_v1`。使用浏览器可公开的 publishable key，不包含服务端密钥。RLS 与列级权限保护编辑令牌摘要、创建时间和其他人的记录。内部专用链接携带随机邀请凭据；普通入口无法读写案例。所有读取与提交均需要邀请凭据，修改还需要独立的单篇凭据。邀请凭据仅保存在专用链接片段与访问者浏览器，不进入源码或静态资源。请按内部协作范围分享专用链接。

正文与人员信息只写入数据库，不进入公开 Git 仓库。浏览器保存草稿与当前设备的修改凭据，不作为多人数据源。现有 Supabase 项目额度由各应用共用。

## 开发

无需安装依赖。`npm test` 检查主题推荐、字段解析和日期校验；`npm run build` 生成静态 `dist/`。数据库部署记录见 `database/schema.sql`。静态资源可部署在 GitHub Pages 或其他静态托管；当前发布由 `.openai/hosting.json` 指定。

## 初筛标准

主题匹配25分、具体行动30分、结果反馈25分、可学习性20分。正文、周期、主题线索、行动和结果均满足要求，且总分达到68分，才进入推荐池。所有分值均为文本线索分，不代表事实已核实。重复表述会降级；同一主题中最多展示3篇，按总分排序并保留原文依据。修改正文后即时重新计算。
