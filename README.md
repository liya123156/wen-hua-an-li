# 文化案例工作台

丽兹行上海文化案例征集。四个目录：粘贴案例、案例库、案例评选、各店提交数量一览表。

## 简单提交

原文写清一个所属店面、一个推荐主题，粘贴故事后逐篇提交即可入库。无需额外确认表单，不强制填写人物、入职日期、事件日期、撰写人、行为点或达到300字。

可连续「新建一篇」保留多篇草稿；每个输入框默认一篇；重复的主题标题、行为点和分隔线不会触发拆分。仅有明确且递增的「案例1 / 案例2」或「第一篇案例 / 第二篇案例」编号时提示拆分，由使用者点击确认后逐篇提交。店面、主题缺失或不明确时不能提交。修改已入库案例使用原记录，不增加提交数量。每篇下方可选填「店总评价」，不填写也可提交。店面推荐的两篇可在评价中注明「店总推荐1 / 店总推荐2」和推荐理由。

## 案例库与提交数量

案例库按月份、价值观、门店及关键词查看。选定门店后，逐篇展开当月完整原文、文字初筛参考分、四项得分和店总评价；上方统计同步切换为本店数据。门店月度集锦及反馈结论包含本店当月全部案例，不受主题或关键词的进一步筛选影响。

门店集锦将本店当月全部案例合成一张PNG长图，一次复制 / 下载即可发送给店总，完整保留各篇原文、评分和店总评价。长图随内容自动加高，分段绘制并编码为一个PNG，避免大画布限制导致截断或缩小文字。给店总的月度反馈自动生成实际篇数、主题分布、目标差额、可复核案例及重点完善方向，并可一键复制。原始字句不会为评分而改写。

BP本人在当前设备提交的案例可直接修改。其他提交人可在已入库卡片或详情中复制该篇专属修改链接，分享给BP；BP打开链接或在「BP修改本篇案例」中导入后即可编辑原文、店总评价。保存更新原记录和评分，不增加提交篇数。沿用原有单篇修改授权，未增加可修改全部案例的统一入口。

数量表包含21家门店、七个主题和行列合计，只按实际入库记录计数，与评选参考分及视频候选状态无关。未提交门店显示0；尚未读取案例时不展示虚假的0。采用大字号、暖紫粉色和爱心，手机可横向滑动。支持复制完整表格PNG图片、下载图片及复制表格文字；图片含全部21家门店，不受视口滚动限制。

表格下方可设置提醒截止日期（24:00前），自动列出提交不足3篇的门店、实际篇数和差额，并生成可直接复制的BP群提醒。默认本月使用当天日期，调整后在当前设备按征集月份保存。这里只控制提醒文案，不锁定案例提交。

## 月会视频候选

依据用户提供的正式价值观解读与行为准则，对照正向行为、负向线索与原文证据。每主题最多推荐3篇，质量不足保留空缺。重点检查主人公、真实场景、关键选择、具体行动和实际影响是否能够构成月会视频叙事。人物与关键事实不清的案例可入库，但不会直接进入视频候选。

文本参考分为：文化准则对应25分、具体行动30分、实际价值25分、可学习性20分。候选需达到80分且通过叙事完整性条件。店总评价中的明确推荐作为额外排序参考（推荐1 +6、推荐2 +4、其他明确推荐 +2），只作用于内容质量已达标的案例，100分内容参考分保持不变；没有评价不扣分。明确事实或贡献归属存疑时先暂停推荐，等待人工核实。采用公开可读的文本规则辅助初筛，属于评选参考，不是大模型语义评审或事实核实；最终由负责人确认。

候选卡片直接标明「文字初筛参考分／100分」，展示文化对应、具体行动、实际价值、可学习性四项实际得分与满分。系统按现有文字的呈现情况计算，仅用于内容初筛；最终入选需人工核实，店总评价另作推荐参考。重复表达导致总分下调时会说明。

每篇可打开「给撰写人 / BP · 修改建议图」：保留原文亮点、3项重点修改、视频准备和核实提醒；出现事实疑点时优先提示核实。采用可复制 / 下载的高清PNG图片，文字也已压缩，不把原有长消息整段转成图片。同主题候选可逐篇切换，每篇对应自己的图片；详情中同样提供图片入口。图片仅在本地浏览器生成，不传往外部图像服务。不虚构事实、采访回答或对白。

## 数据与部署

复用既有Supabase项目的独立表 culture_cases_v1。按用户要求，工作台链接无需访问码即可查看案例和提交。旧邀请链接也能打开，目录切换后不再保留访问码。RLS仍限制修改须使用单篇专属修改凭据，不开放匿名删除，编辑密钥哈希不对外提供。浏览器保存草稿与本设备的修改凭据，正式案例保存在共享数据库。

源数据库结构见 database/schema.sql，先应用简化提交增量 database/simplify-submission.sql，再应用公开入口与可选评价增量 database/public-access-manager-review.sql。schema.sql 为最初结构快照，完整现状需按顺序应用两个增量。已有案例内容不作批量修改。

无需安装依赖。npm test 验证分类识别、缺失和歧义阻断、多篇拆分、21×7数量合计、店总评价排序参考、视频候选、动态提交提醒及可复制的修改文字。npm run build 生成静态 dist/。
